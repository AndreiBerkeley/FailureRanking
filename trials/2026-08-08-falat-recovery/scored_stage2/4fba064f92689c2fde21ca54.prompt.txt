Web query classification | A Web query topic classification/categorization is a problem in information science. Different from the document classification tasks, queries submitted by Web search users are usually short and ambiguous; also the meanings of the queries are evolving over time.  Therefore, query topic classification is much more difficult than traditional document classification tasks.
