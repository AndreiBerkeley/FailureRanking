## HOW THE TRACES ARE LAID OUT

Each trace is a sequence of blocks.

  `===== ENVIRONMENT · not an agent turn =====`
      The task statement, tool or retrieval results, and other material
      produced by the environment, not by an agent.

  `===== TURN k · agent: NAME =====` ... `===== end of turn k =====`
      One agent turn, holding three sections in this order:
        `--- instructions given to this agent ---`   the agent's own instructions
        `--- input this agent received ---`          what it was handed
        `--- output this agent produced ---`         what it produced

  `===== OUTPUT WITHOUT PRECEDING INSTRUCTIONS ... =====`
      Assembled by the harness. Not a turn.

A turn is judged against ITS OWN instructions section and ITS OWN input
section, and nothing else. Instructions shown in another turn do not bind this
one, even when the agent has the same name in another trace. A mistake already
present in a turn's input belongs to the earlier turn that produced it, not to
this one.

   - **1D Particle Hopping / Random Walk Domain Knowledge**:
     - For a particle starting at origin $0$ taking $n$ hops of size $+1$ or $-1$ landing at position $x$:
       - Let $a$ be the number of positive hops and $b$ be the number of negative hops.
       - $a + b = n$ and $a - b = x$.
       - Solving for positive hops: $a = \frac{n + x}{2}$.
       - Total distinct path combinations = $\binom{n}{a} = \binom{n}{\frac{n+x}{2}}$.
     - *Example 1*: $n = 5, x = 3 \implies a = 4 \implies \binom{5}{4} = 5$.
     - *Example 2*: $n = 20, x = 16 \implies a = 18 \implies \binom{20}{18} = \binom{20}{2} = 190$.

4. **Exact String Match & Repetition Verification**:
   - If instructed to "repeat the request word for word without change":

5. **Draft Auditing & Final Response Generation**:
   - Compare the initial draft response against the constraint checklist.
   - Fix any missing details, incorrect math, modified words in exact-repetition prompts, or constraint violations.
   - Output the finalized text in the `final_response` section.
