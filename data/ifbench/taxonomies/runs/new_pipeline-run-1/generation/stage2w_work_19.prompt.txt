import datetime
import re

class MultilingualDiaryEntry:
    """
    A class to represent a digital diary entry supporting multiple languages
    and flexible timestamp formatting.
    """
    SUPPORTED_LANGUAGES = {'en', 'fr', 'es'}

    def __init__(self, title, entry_text, mood, weather, lang='en'):
        self.title = self._validate_string(title, "Title")
        self.entry_text = self._validate_string(entry_text, "Entry text")
        self.mood = self._validate_string(mood, "Mood")
        self.weather = self._validate_string(weather, "Weather")
        self.lang = self._validate_language(lang)
        self.timestamp = datetime.datetime.now()

    def _validate_string(self, value, field_name):
        if not isinstance(value, str) or not value.strip():
            raise ValueError(f"{field_name} must be a non-empty string.")
        return value.strip()

    def _validate_language(self, lang):
        if lang not in self.SUPPORTED_LANGUAGES:
            raise ValueError(f"Language '{lang}' is not supported. Use: {self.SUPPORTED_LANGUAGES}")
        return lang

    def display_timestamp(self, use_24_hour=True):
        if use_24_hour:
            return self.timestamp.strftime("%Y-%m-%d %H:%M:%S")
        else:
            return self.timestamp.strftime("%Y-%m-%d %I:%M:%S %p")

    def get_entry_summary(self):
        translations = {
            'en': {"title": "Title", "mood": "Mood", "weather": "Weather"},
            'fr': {"title": "Titre", "mood": "Humeur", "weather": "Météo"},
            'es': {"title": "Título", "mood": "Estado de ánimo", "weather": "Clima"}
        }
        t = translations[self.lang]
        return f"{t['title']}: {self.title}\n{t['mood']}: {self.mood}\n{t['weather']}: {self.weather}"

    def analyze_sentiment(self):
        """

            # Simulated API call logic

            if text_len > 100:
                return "Positive"
            return "Neutral"
        except Exception as e:
            return f"Error connecting to sentiment API: {e}"

2. **Multilingual Support**: The `SUPPORTED_LANGUAGES` class attribute acts as a single source of truth. By defining a dictionary of labels in the `get_entry_summary` method, we ensure that the user interface can remain localized based on the `self.lang` attribute. This approach is easily extensible—one could move the dictionary to a JSON file or a database to support dozens of languages without modifying the core logic.

3. **Time Handling**: Python's `datetime` module is highly capable. By providing a boolean parameter `use_24_hour`, the user can toggle between ISO standards and more regional 12-hour conventions. This is essential for international applications where time perception varies significantly between demographics.

4. **Sentiment Analysis Integration**: The `analyze_sentiment` method is designed with a try-except block to gracefully handle network errors. When implementing this in production, you might replace the logic with:
