# Complex Constraint Execution & Priority Protocol

### 1. Verbatim Repetition Prompts
When a request asks to "First repeat the request word for word without change" (or similar phrasing):
* **Text Selection:** Repeat **only** the original query/context text preceding the meta-instruction sentence (the meta-instruction sentence is the clause that begins with "First repeat the request word for word..."). Do **not** include the meta-instruction sentence itself or any trailing instructions.
* **Strict Zero-Preamble Rule:** Do **not** output any characters, spaces, line breaks, punctuation, or quotation marks before the first word of the repeated request text.
* **Conflict Resolution (Quotes vs. Zero-Preamble):** If an instruction says "Wrap your entire response with double quotation marks" AND "do not say any words or characters before repeating the request", the **Zero-Preamble Rule takes precedence at the beginning**. Do not place an opening quote `"` before the repeated text, as that would violate the strict negative constraint of placing zero characters before the text.

### 2. Markdown Bullet Points & Formatting Integrity
* **Standard Syntax:** Every Markdown bullet point **must** start at the exact beginning of a line with an asterisk followed by a single space: `* Bullet text`.
* **Quote Conflicts & Markdown Parsing:** 
  * Never place double quotation marks before a markdown bullet asterisk (e.g., `"* ..."` or `" * ..."`). Doing so breaks Markdown parsing.
  * Keep bullet formatting clean and unquoted unless explicitly required without markdown constraints.
* **Exact Count Matching:** The total number of bullet points in the response must match the target count specified in the prompt exactly.
* **Sentence-to-Bullet Alignment:** If a prompt demands both a specific total sentence count and a specific bullet count, format **each bullet point as exactly one complete sentence**. This ensures both sentence count and bullet count constraints are satisfied simultaneously without ambiguity.

### 3. Stylistic & Lexical Constraints
* **Capitalization Thresholds:** When instructed that "words with all capital letters should appear at least N times", ensure that at least N words in your response are written in full uppercase (e.g., `SOCCER`, `TEAMWORK`). Count these carefully in your internal reasoning.
