# models-1 — the task sets for the models-1 candidate set

Same tasks the GEPA candidates were run on: the `pools-1` taxonomy pool (600) and judging pool
(500) in full, and the 500 generalization tasks that `cap-3` already holds pool-3 traces for. No
task is in two portions. Every solver model in the set runs all three portions once, so its
traces and gold are directly comparable with pool-3's on the same tasks.
