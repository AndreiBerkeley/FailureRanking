A substantive step is any point where the program did work: a calculation, a
transformation, a comparison, an inference, an application of a rule or
definition, a judgement about the material, a decision about what to do next.

THE FIRST STEP IS ALWAYS INTAKE. Before anything else, check what this part of
the program understood from what it was handed. Did it read the task correctly?

material it was given without corrupting or dropping any of it? A program that
starts from a misreading is wrong from that point on, however sound everything
after it looks.

ASSUME WHAT IT RECEIVED IS CORRECT, AND JUDGE ONLY WHAT IT DID WITH IT. If the
material handed to a part of the program was already wrong, acting on it is not
that part's mistake — it belongs to whatever produced it. But if the material was

it is exactly the kind this pass exists to catch.

around, or happened to compensate for is still a mistake and is still reported.
Whether it survived to the end is a separate question from whether it occurred.
