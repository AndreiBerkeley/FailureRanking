# split-5 — gold scores across random subsamples of 50–100 tasks

Thirty recorded subsamples drawn from split-3's 500 unseen tasks, five at
each of six sizes, each scored against the 500 minus its own tasks. **No
capture and no judging was run**: every trace and gold score already existed.
Subsamples overlap each other by construction — 500 tasks cannot supply many
disjoint sets this large — so they are independent draws, not a partition.

Generated by `scripts/report_subsamples.py`; numbers in `scores.json`.
