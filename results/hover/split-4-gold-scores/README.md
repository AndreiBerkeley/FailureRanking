# split-4 — gold scores per measurement set

Four disjoint 50-task measurement sets scored against split-3's 500-task
`generalization` portion. **No capture and no judging was run for this**: every
trace and every gold score already existed under
`benchmarks/hover/traces/traces-3/`. set-A is split-3's `judging` portion;
set-B/C/D are drawn from the generalization portion itself.

A set is scored against **the 500 minus its own 50 tasks** — 500 for set-A,
which comes from a different portion, and 450 for set-B/C/D. Scoring a set
against a target it is 10% of is self-correlation: set-B reads +0.907 clean
and +0.965 leaky. Exclusion costs nothing measurable (46/66 pairs separable
at both 500 and 450; SE 0.0221 vs 0.0233).

Generated by `scripts/report_scores.py`; numbers in `scores.json`.
